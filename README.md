## Contenido del Curso

Los ejercicios se encuentran divididos según los bloques temáticos del curso:

1. **Introducción y Entrada/Salida**: Datos básicos, operadores y expresiones.
2. **Estructuras Condicionales**: `if`, `else`, `switch`.
3. **Estructuras Repetitivas**: Bucles `while`, `do-while` y `for`.
4. **Arreglos / Vectores**: Manipulación de listas unidimensionales.
5. **Matrices / Tablas**: Manipulación de arreglos bidimensionales.
6. **Cadenas de Caracteres**: Manejo de `char[]` y librería `string.h`.
7. **Estructuras (Structs)**: Modelado de datos complejos.
8. **Funciones**: Paso de parámetros por valor y por referencia, recursividad.
9. **Punteros**: Gestión explícita de memoria y direccionamiento.
10. **Pilas, Colas y Listas Enlazadas**: Estructuras de datos dinámicas.
11. **Árboles Binarios**: Creación, inserción y recorridos (`preorden`, `inorden`, `posorden`).
12. **Archivos de Texto**: Lectura, escritura y persistencia de datos.
13. **Programación Orientada a Objetos (POO)**: Clases, objetos, herencia y polimorfismo.
